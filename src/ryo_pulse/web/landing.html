The gap

A single hit isn't a pattern

Agents treat one appearance in a momentum scan as a lasting signal. RYO had no tool that asks: did this token keep showing up under the same scan?

scan_market: one moment

"PEPE is ranked #1." But was it there an hour ago? Will it be there next scan?

Pulse: the pattern

"PEPE is emerging: first seen 2 scans ago, present in the newest." It's a real signal, but not a pattern yet.

One status, always

Five honest answers

Each status comes with counts, coverage, first and last seen, a streak and a plain-language reason. There's no LLM judgement and no price prediction.

persistent

Keeps showing up across the window.

emerging

Showing up now, only recently. A signal, not yet a pattern.

transient

Showed up, then faded or appeared only sporadically.

absent

Enough good scans, and it never appeared.

insufficient

Not enough comparable, successful scans to say.

How it works

Collect, classify, monitor

Pulse uses RYO's read-only research tools over MCP. It can't buy, sell or move anything.

Collect

Pulse takes a RYO market scan on a schedule, along with RYO's read on the market mood.

Classify

It compares each token across scans taken with the same settings and gives one clear status.

Monitor

The dashboard shows what changed since the last scan first, most important on top, with settings you control.

It won't invent absence

Most scanners quietly turn an outage into "not there". Pulse refuses to.

Outages lower coverage

A failed or "unavailable" scan is stored as failed. It never counts as the token being gone, and if coverage drops the answer is insufficient.

Like is compared with like

Every scan's settings are hashed into a profile. Scans with different settings are excluded, so one hash means one comparable series.

Replayable

Every answer comes with a replay code. Rerun it from the saved scans and you get the exact same result, so nothing can be quietly changed.
